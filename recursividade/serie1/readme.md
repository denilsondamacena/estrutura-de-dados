## Série 1

### Exercício 1
>Escreva uma função recursiva que calcule o somatório dos N primeiros
números naturais. A função deve retornar zero para números negativos.

### Exercício 2
>Escreva uma função recursiva que, recebendo um vetor de inteiros, o
tamanho do vetor e o valor da última posição como primeiro menor valor,
retorne o menor valor contido no vetor.

### Exercício 3
>Escreva uma função recursiva que exiba o fatorial de um número. Pela
limitação da recursividade, a entrada deve ser baixa — adote 12 como
limite.

### Exercício 4
>Escreva uma função recursiva que exiba o total de elementos negativos
de um vetor de inteiros de N posições, passado como parâmetro.

### Exercício 5
>Escreva uma função recursiva que, recebendo um inteiro N, apresente o
resultado da soma S = 1 + 1/2 + 1/3 + 1/4 + … + 1/N. Para que a
divisão de dois inteiros devolva um double, converta com cast: double x
= 1 / (double) n;

### Exercício 6
>Resolva a soma de dois números naturais **sem usar operação de soma**
— nem operador aritmético, nem função de qualquer classe ou
biblioteca. Apenas uma função recursiva.
